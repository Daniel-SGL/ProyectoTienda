# 🛒 Servidor y Lógica de Negocio - Tienda Web

Proyecto académico enfocado en el desarrollo del **backend** para una plataforma de comercio electrónico, desarrollado por **Daniel** y **Ángel**.

---

## 📌 Descripción del Proyecto

Este proyecto consiste en el diseño y desarrollo de la capa de servidor para la gestión de una tienda electrónica. La aplicación proporciona toda la lógica interna y el procesamiento de datos necesarios para administrar el catálogo de productos, la gestión del carrito de compras, la autenticación de usuarios y la administración de pedidos.

## 🚀 Tecnologías Utilizadas

- **Lenguaje / Framework de Servidor: PHP
- **Base de Datos:** MariaDB
- **Control de Versiones:** Git & GitHub

---

## ✨ Características Principales

- 🔐 **Autenticación y Seguridad:** Registro e inicio de sesión de usuarios con validación de credenciales.
- 📦 **Gestión de Productos:** Procesamiento y administración de los datos del catálogo y categorías.
- 🛒 **Gestión del Carrito:** Control y actualización del contenido del carrito de cada usuario en el servidor.
- 📋 **Procesamiento de Pedidos:** Registro y generación de compras en la base de datos.
